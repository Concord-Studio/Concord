try (name[, acceptRejected])
Returns true and the ComponentClass if one was registered with the specified name or false and an error otherwise

Parameters:

  • name string Name of the ComponentClass to check
  • acceptRejected boolean Whether to accept names prefixed with the Reject Prefix. (optional)

Returns:

  1. boolean ok
  2. Component or string ComponentClass on success, or an error string on failure
  3. string or boolean On success: the stripped Component name if the name had the Reject Prefix, otherwise false
