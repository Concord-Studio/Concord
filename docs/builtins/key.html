Builtin key

Built-in Component that assigns a unique key to an Entity in its World.

The Entity must belong to a World. Calling the Component returns the key value.

Functions

Key:deserialize (data) Assigns a key from serialized data.
Key () Returns the key value.
Key:removed (replaced) Callback: Clears the World key when the Component is removed (not replaced).
